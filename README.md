# Pandas Data Analysis & Visualization

## Project Overview: 
This project demonstrates practical data analysis and visualization using *Python, Pandas, Matplotlib, and Seaborn*. It is designed as part of a Python internship task to showcase fundamental skills in data handling, statistical analysis, and graphical representation of insights.

## Objectives:
- Load and explore real-world tabular data  
- Perform basic statistical analysis  
- Compute key numerical summaries  
- Visualize patterns using multiple plot types  
- Interpret relationships between variables

## Features:  
The program performs the following:  
Reads a CSV dataset  
Displays first five rows of data  
Generates descriptive statistics (mean, min, max, std, etc.)  
Calculates average of a numeric column  
Creates:  
- Bar Chart  
- Scatter Plot  
- Correlation Heatmap
